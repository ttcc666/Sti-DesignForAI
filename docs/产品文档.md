## 1. 产品定义

**一句话：** 装在 Windows 上的标签出稿工位——中间仍是 Stimulsoft 设计器，左边用白话出草稿和改稿，右边管字段和本机打印机。

**解决的问题：** 出一张标签慢、改旧稿容易绑错字段、设计和现场打印对不齐。

**不是什么：** 不是网站，不是聊天机器人，不是自动下发产线的排产系统，也不是抛弃 STI 另做一套画布。

**产品原则（按优先级）：**

1. **打得出、绑得对** 高于「生成得好看」。
2. **人是最终编辑者**：任何自动结果都可以改、可以撤、可以不用。
3. **画布是主界面**：对话是助手栏，不抢主操作。
4. **AI 可关**：没网、没模型，设计、预览、打印必须可用。
5. **兼容旧资产**：现有 `.mrt` 能打开、能保存、能再打开。

## 2. 目标与非目标

### 2.1 第一期目标

| 编号 | 目标 | 可验收 |
| --- | --- | --- |
| G1 | 模板人员用本程序完成打开、编辑、保存、预览、本机打样 | 现有一张 `.mrt` 在目标打印机打出合格样张 |
| G2 | 常用物料标签可用白话或勾选字段生成可编辑草稿 | 一次会话 + 少量微调即可打样 |
| G3 | 字段只能来自字典，不能由模型编造列名 | 绑定不存在的字段时明确失败并提示 |
| G4 | 关闭 AI 后主流程完整可用 | 对话栏仅提示不可用，不挡设计与打印 |

### 2.2 非目标（第一期不做）

| 编号 | 不做 | 说明 |
| --- | --- | --- |
| N1 | 网站 / 浏览器设计 | 打印和桌面设计器对不齐 |
| N2 | 自动发布到产线 | 必须人确认样张 |
| N3 | ERP/WMS 实时套打 | 第一期只用本地示例数据（JSON / Excel） |
| N4 | 多人同时编辑、在线审批 | 文件用本地或共享盘即可 |
| N5 | 批量仓别 / 语种变体 | 放到后续版本 |
| N6 | 承诺「模型保证扫码通过」 | 扫码以真机为准 |
| N7 | 手机端 | 不在范围内 |

## 4. 产品形态

| 项 | 规格 |
| --- | --- |
| 运行环境 | Windows 10/11，桌面安装包 |
| 主界面 | 单一主窗口，三栏 + 顶栏 + 状态栏 |
| 模板载体 | 本地或共享盘上的模板文件。一张标签由 `.label.json`（结构，程序内部的唯一事实来源）和同名 `.mrt`（交给 Stimulsoft 的报表）成对组成；打开 `.mrt` 时读取旁边的 `.label.json` |

## 5. 信息架构与主界面

### 5.1 窗口结构

```
顶栏：文件 | 打印机 | 模型设置 | 版本 | 帮助
左栏：对话（可折叠）
中栏：STI 设计器（默认最宽，≥ 窗口一半）
右栏：字段 / 页规格 / 打印机 / 示例数据（可折叠）
底栏：文件名 · 页尺寸 · 打印机 · 模型状态 · 保存状态
```

### 5.2 各区域产品规格

#### 顶栏

| 菜单 | 命令 | 说明 |
| --- | --- | --- |
| 文件 | 新建、打开、保存、另存为、最近文件、退出 | 未保存关闭须提示 |
| 打印机 | 选择打印机、页面设置、打印预览、打样 | 打印机来自本机队列 |
| 模型设置 | 启用/停用、地址、模型名、密钥、测连通 | 密钥不明文展示 |
| 版本 | 另存一版、查看历史、恢复到某版 | 恢复前若有未保存更改须确认 |
| 帮助 | 快捷键、关于 | 第一期不做在线教程站 |

当前实现与上表的差距：菜单为「文件 / 打印机 / 模型设置 / 版本」四项，尚无「帮助」；页面设置在右栏而非打印机菜单；查看历史与恢复目前走对话（列出版本、打开某版），版本菜单只有「另存一版」。这三项排到 1.1。

#### 左栏 · 对话

- 默认宽度约 280–320 px，可拖窄、可折叠。折叠后中栏自动变宽。
- 组成：会话列表（第一期单会话即可）、消息区、输入框、发送、停止。
- 每条助手回复若产生了画布变更，必须带 **应用到画布**（已自动应用则显示「已应用」）和 **撤销本次**。
- 未配置模型或离线：输入框禁用，展示原因和「去设置」链接。不弹模态挡设计器。
- 语气：短、说做了什么、下一步可以做什么。不解释引擎原理。

#### 中栏 · 设计器

- 产品主操作面。用户可在此拖拽、改属性、撤销（设计器自身撤销与「撤销本次 AI」分开，见 9.4）。
- 展示的是可编辑模板，不是效果图。
- AI 写入与用户拖拽冲突时，以用户在设计器中的操作为准，并在对话里说明未应用的部分。

#### 右栏

四个区块，当前实现为单列可滚动面板（非页签），自上而下依次是字段、页规格、打印机、示例数据：

| 区块 | 内容 | 操作 |
| --- | --- | --- |
| 字段 | 当前字典的字段名、中文名、类型、是否已绑到画布 | 增删字段；勾选后可「按所选生成草稿」；「插入图片」直接放一张图 |
| 页规格 | 常用尺寸预设、方向、边距（毫米） | 切换预设须确认，避免无意改纸 |
| 打印机 | 本机打印机列表、当前纸张 | 刷新列表；无打印机时预览仍可用、打样禁用 |
| 示例数据 | 一行或多行示例，来自 JSON / Excel | 用于预览和打样，不写回模板结构 |

#### 状态栏（只读）

`文件名.mrt  ·  70 × 40 mm  ·  打印机名称 / 未选择  ·  模型：在线 | 离线 | 未配置  ·  已保存 | 未保存`

## 6. 功能规格

编号规则：`F` 模块。`P1` 第一期必须，`P2` 第二期，`P3` 以后。

### F1 文件与模板（P1）

| 项 | 规格 |
| --- | --- |
| 新建 | 选页规格预设后出现空白标签页，进入设计器 |
| 打开 | 打开 `.mrt`；打不开时说明原因，不覆盖当前未保存稿（先提示保存或另开） |
| 保存 / 另存为 | 写回 `.mrt`；保存成功后状态栏「已保存」 |
| 最近文件 | 记住最近 10 个路径，缺失则从列表移除并提示 |
| 兼容 | 以 Stimulsoft 能打开为准；打得开的稿必须能再保存后打开 |

**验收**

- 用业务提供的至少 1 张现有 `.mrt`：打开 → 微调一字 → 保存 → 再打开，主内容仍在。
- 未保存时关闭窗口，提示「保存 / 不保存 / 取消」。

### F2 设计器（P1）

| 项 | 规格 |
| --- | --- |
| 组件 | 文本、条码、二维码、图片、直线、矩形、椭圆/圆、三角、圆角框、勾选框 |
| 文字 | 字体、字号、加粗/斜体/下划线、颜色、底色、水平与垂直对齐、旋转、边框；装不下时可选换行 / 自动缩字 / 裁切 |
| 条码 | 39 种制式，含零售（EAN/UPC/JAN/ISBN）、工业（Code128/39/93/11、Codabar、ITF-14、2of5）、GS1 家族（GS1-128、SSCC-18、GS1 DataMatrix、GS1 QR）、二维（QR、DataMatrix、PDF417、Aztec、Maxicode）、邮政（Postnet、IntelligentMail、RoyalMail 等）。GS1 内容用 `(01)…(17)…(10)…` 的 AI 括号写法。本机引擎不支持 GS1 DataBar |
| 单位 | 页规格与产品文案统一用毫米 |
| 编辑权 | 用户随时可改 AI 生成的任何对象 |
| 嵌入失败降级 | 设计器弹窗模式；主窗口仍保留对话、字段、打印、状态栏 |

**验收**

- 用户不经过对话，仅用设计器能完成一张简单标签并保存。
- 设计器内撤销/重做可用（走 STI 自身能力）。

### F3 页规格与打印机（P1）

| 项 | 规格 |
| --- | --- |
| 预设 | 内置 70×40、100×50、100×60（mm），待业务确认后调整 |
| 自定义 | 允许输入宽高（mm）和边距 |
| 方向 | 竖向 / 横向。切换方向即对调页宽高，并把内容收回页内 |
| 打印机 | 枚举本机队列；记住上次选择 |
| 切换确认 | 已有内容时改页尺寸，提示可能裁切或需重排 |

**验收**

- 无打印机时：预览可用，打样按钮禁用并说明「未检测到打印机」。
- 切换 70×40 → 100×60 会弹出确认。

### F4 字段字典与示例数据（P1）

| 项 | 规格 |
| --- | --- |
| 字典来源 | 本机 SQLite 字典（全局一份），首次启动写入默认集 |
| 默认字段（待业务确认前） | 物料编码、品名、规格、批次、数量、生产日期、仓库 |
| 维护 | 用户可在右栏增删；也可在对话里口述新字段名，助手先登记进字典再使用。可改显示名与类型（文本 / 数字 / 日期） |
| 导入补齐 | 打开旧模板时，模板里出现的字段若字典中没有则自动登记并勾选，避免旧稿绑定悬空 |
| 绑定 | 组件只能绑字典中的字段，或写死字面量 |
| 示例数据 | 加载一份 JSON；助手可读写单个字段的示例值 |
| 展示 | 已绑定 / 未绑定状态可见 |

**验收**

- 「按所选字段生成草稿」只使用勾选字段，不出现未勾选字段。
- 对话要求绑定不存在的字段时，助手拒绝并列出可用字段。

### F5 预览与打样（P1）

| 项 | 规格 |
| --- | --- |
| 预览 | 用当前示例数据渲染，所见接近打印 |
| 打样 | 打当前模板 + 当前示例数据的第一行（或当前选中行） |
| 一致性 | 预览与打印使用同一套本机字体与打印机设置 |
| 失败 | 预览/打印失败给出可读原因（无数据、无打印机、引擎错误），不静默 |
| 打样前 | 建议先做一次出稿体检（F10）；助手在打样、保存前会主动体检并先报问题 |

**验收**

- 同一份示例数据，预览与打样字段内容一致。
- 无示例数据时提示先加载，不打出全空标签除非用户确认「仍要打印」。

### F6 版本（P1 最小 / P2 完善）

| 项 | P1 | P2 |
| --- | --- | --- |
| 另存一版 | 生成带时间戳的副本 | 同一条目下多版本列表 |
| 查看 | 在对话里列出最近 20 版（按时间倒序） | 版本面板 |
| 恢复 | 打开该副本即可，可让助手直接打开某一版 | 一键恢复 + 与上一版差异摘要 |
| 说明 | 可选备注 | 备注 |

**P1 验收：** 用户能「另存一版」并在文件夹中找到副本，不覆盖正在编辑的文件（除非用户选了保存）。

### F7 对话助手（P1 后半）

助手只能通过工具改模板，不向用户输出 `.mrt` 或 XML。能力按下面几组划分，组外的先说明做不到，不假装做了。完整工具清单见[附录 A](#附录-a助手工具清单)。

| 能力组 | 用户意图示例 | 产品行为 | 优先级 |
| --- | --- | --- | --- |
| 出草稿 | 「70×40 物料标签，要编码、品名、批次、QR」 | 按页规格和字段生成可编辑草稿并铺到设计器 | P1 |
| 按字段出草稿 | 右栏勾选后点按钮，或「按已选字段做一张」 | 同上，字段集合以勾选为准 | P1 |
| 看懂现状 | 「这张有哪些字段、有什么风险」「批次那块什么设置」 | 列出页尺寸、组件、绑定与明显风险；可单查某个组件的全部属性 | P1 |
| 增量修改 | 「加一个生产日期」「批次字号加大」「品名装不下」 | 只改说清的部分；大改（换纸、重排）先列出再确认 | P1 |
| 排版 | 「这三块左对齐」「间距均匀」「复制一份」「这两块换位置」 | 对齐、分布、等宽高、复制、互换、层次、锁定、隐藏 | P1 |
| 字段与绑定 | 「品名绑物料名称」「加个仓库字段」 | 校验字典后绑定；字典没有的字段先登记再用，或列出可用字段 | P1 |
| 条码 | 「换成 GS1-128」「这个 QR 加纠错」 | 换制式、改内容、纠错级别、显示码文；GS1 走 AI 括号写法 | P1 |
| 图片 | 「左上角加 logo」「换成这张图」 | 插入或替换本机路径 / http 图片 | P1 |
| 页面与打印机 | 「改成横向」「按这台打印机改边距」 | 页规格、方向、边距、按所选打印机可说明的项调整 | P1 |
| 出稿闭环 | 「体检一下」「打样」「导出 PDF」「保存」「回上一版」 | 体检、预览打样、导出、保存、最近文件与历史版本 | P1 |
| 兜底 | 「刚才那下不要了」 | 撤销本轮全部改动 | P1 |
| 批量变体 | 「做出东仓西仓两套」 | 明确「本期不做」 | P2 |
| 接业务系统取数 | 「去 ERP 拉这个物料」 | 明确「本期不做」 | P3 |

**出草稿规则**

- 结果必须是设计器里的对象，不是一张图。
- 未指定的字段不出现。
- 未指定页规格时，用当前右栏规格；都没有则先问用户选预设。
- 生成后状态为未保存。

**改稿规则**

- 换页尺寸、删多个组件、重排整张：先列出将要做的事，用户点确认再执行。
- 加一个组件、改一句文案、改一个字号：可以直接做，并提供「撤销本次」。
- 改已有组件前先看清单或单查该组件，用组件 id 指定，不靠猜。
- 只为改位置、字号或一句标题时，不许重建整张。
- 旧稿中助手看不懂的部分：只读说明「这部分请在设计器里改」，不得删除或覆盖。

**验收**

- 固定口令「做一张 70×40 物料标签，要物料编码、品名、批次、QR」能在当前字典下生成对应四类内容并出现在画布。
- 再发「加一个生产日期」只增加该字段，不重建整张。
- 发送「把品名绑到 FooBar」（字典无此字段）→ 不改画布，提示可用字段。
- 点「撤销本次」后，画布回到该条回复之前。

### F8 设置与离线（P1）

| 项 | 规格 |
| --- | --- |
| 模型 | 启用开关、服务地址、模型名、密钥 |
| 测连通 | 成功/失败及失败原因 |
| 密钥 | 本机保存，界面掩码；不进安装包、不进模板文件 |
| 离线 | 设计器、字段、预览、打印全部可用；仅对话不可用 |
| 模板默认目录 | 可改；记住上次目录 |

**验收：** 断开网络或关闭「启用模型」后，打开、保存、预览、打样仍可用。

### F9 导出（P1）

| 项 | 规格 |
| --- | --- |
| 格式 | PDF、PNG |
| 数据 | 用当前示例数据渲染，与预览一致 |
| 路径 | 用户选择保存位置；对话里可直接说导出，未给路径时弹选择框 |
| 用途 | 发给业务确认、留档、无打印机的机器上看效果 |

**验收：** 导出的 PDF 页尺寸与页规格一致，内容与预览一致。

### F10 出稿体检（P1）

打样和保存前的一次自检，只报问题不自动改。

| 检查项 | 说明 |
| --- | --- |
| 条码内容 | 按制式校验，位数、字符集、GS1 括号写法不符时指出 |
| 空绑定 | 组件绑了字段但字段已不在字典，或既无绑定也无文字 |
| 缺图 | 图片路径不存在 |
| 超页 / 贴边 | 组件越出页面或压到边距 |
| 重叠 | 明显互相压盖的组件 |

**验收**

- 把 EAN-13 内容写成 12 位，体检必须报出位数不符。
- 体检通过的稿，打样不因上述问题出废样。

## 7. 核心对象（产品语言）

开发和界面用同一套叫法。

| 对象 | 用户能理解的含义 |
| --- | --- |
| 模板 | 一张标签的 `.mrt` 文件 |
| 草稿 | AI 或「按字段生成」铺到设计器上的可编辑结果 |
| 字段 | 字典里的一列，如「物料编码」 |
| 绑定 | 某个组件显示该字段的值，而不是写死文字 |
| 字面量 | 写死在模板上的固定文字 |
| 示例数据 | 用来预览/打样的一行或多行假数据/抽样数据 |
| 页规格 | 宽高（mm）、方向、边距 |
| 一版 | 一次有意义的保存副本，便于回退 |
| 本次变更 | 对应一条助手回复所改动的内容，可整笔撤销 |
| 组件 | 画布上的一块内容，如一行文字、一个条码、一张图 |
| 制式 | 条码的类型，如 Code128、EAN-13、GS1-128、QR |
| 溢出处理 | 文字装不下时怎么办：换行、自动缩字、裁切 |
| 体检 | 打样前的一次自检，列出会导致废样的问题 |
| 导出 | 把当前稿加示例数据输出成 PDF 或 PNG |

用户界面不出现「IR」「适配器」「.mrt XML」等词，除非帮助里的高级说明。

## 8. 用户流程

### 8.1 从零出一张新标签

1. 文件 → 新建 → 选页规格（或沿用默认）。
2. 右栏勾字段，点「按所选生成草稿」；或左边用一句话说需求。
3. 中栏出现草稿。用户调位置、字号、对齐。
4. 加载或确认示例数据 → 预览。
5. 选打印机 → 打样。
6. 保存或另存一版。

异常：模型不可用时，步骤 2 只走「勾字段生成」（规则草稿）或纯手搭。不允许卡在对话上。

### 8.2 改一张旧模板

1. 打开 `.mrt`，中栏为原样。
2. （可选）问「有哪些字段、有什么风险」。
3. 说要改的内容。大改先确认。
4. 预览、打样、另存一版（建议不直接覆盖正式文件，产品在首次「打开后保存」可提醒另存，不强制）。

### 8.3 不用 AI 的完整闭环

新建或打开 → 设计器编辑 → 示例数据预览 → 打样 → 保存。左栏折叠即可。

## 9. 对话产品规则

### 9.1 人格与文案

- 自称工作台助手即可，不拟人。
- 回复结构：做了什么 → 画布哪里变了 → 可选下一步（预览 / 继续改）。
- 做不到就说做不到，并给出设计器里怎么手动做（一句）。

### 9.2 禁止行为

- 编造字典里没有的字段并写进模板。
- 在用户未确认时大幅重排或删多块内容。
- 输出模板源文件或长段技术 XML 给用户改。
- 声称「打印后一定能扫过」。
- 在离线时假装已改画布。

### 9.3 实时的产品定义

「实时」= 用户发送后，数秒内画布出现可见变化（或先出现「将要改动的清单」等待确认）。不是字一个个刷出整张标签。

生成过程中：输入框变为可停止；已应用的部分保留，停止后可撤销本次。

### 9.4 撤销模型

| 动作 | 范围 |
| --- | --- |
| 撤销本次（对话按钮） | 撤掉这一条助手回复对画布的全部改动 |
| 设计器撤销 | STI 常规一步步撤，与「本次」可以并存 |
| 恢复版本 | 回到某次另存的文件 |

两者冲突时的产品规则：用户刚点了「撤销本次」，则以该快照为准，清掉中间的设计器细撤栈（若做不到，则提示「请用设计器继续撤」）。P1 优先保证「撤销本次」可靠。

### 9.5 冲突

用户正在拖拽时，助手补丁不得覆盖该组件；对话说明「你正在改这块，我没动它」。

## 11. 发布与版本规划

### 1.0（第一期）— 工位可用

- F1–F6 最小、F7 各能力组、F8、F9、F10。
- 成功标准：
  1. 模板人员愿意用本窗口代替「单独开 STI + 记事本对字段」。
  2. 常用物料标签：一次会话或一次勾选生成 + 少量微调即可打样。
  3. 关闭 AI 仍能改完、存完、打完。
  4. 业务指定的 2～3 种尺寸，在目标打印机上打出可接受样张。

### 1.1（第二期）— 改旧稿更稳

- 旧稿分析更完整；版本面板（列表 + 一键恢复 + 与上一版差异说明）；谨慎的自动重排；批量变体（仓别/语种）可试点。
- 补第一期欠下的界面项：帮助菜单、打印机菜单里的页面设置入口、Excel 示例数据。

### 2.0（第三期）— 现场打印

- 现场人员模式（少设计、多选模板套打）；可选接业务数据；共享模板目录约定。
